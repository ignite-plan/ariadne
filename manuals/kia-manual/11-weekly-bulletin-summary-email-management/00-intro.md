**Bulletin Summary Email Management**

- This feature allows you to generate post summaries for each bulletin created in the BO system and send them via email.

- Bulletin summaries can be created either on a **weekly basis** or for a **specific date range**.

- Users with **Write** permission can generate bulletin summaries.

- Users with **Read** permission can view the generated summaries.
