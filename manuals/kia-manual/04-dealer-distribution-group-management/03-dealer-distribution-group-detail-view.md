## Dealer Distribution Group Detail View

![Group Detail](images/group-detail.png){width=6.26in}

- Selecting **Detail** in the list view opens the group's detail screen.

**Dealer group information**

- Dealer group name: Group name.

- Description: Group description.

- Dealers: Number of dealers assigned to this group.

- Dealer status: Number of dealers by status.

**Dealer list**

- Displays the list of dealers assigned to the group.

  - **No**: Sequence number.

  - **Dealer name**: Dealer name.

  - **Dealer no.**: Dealer number.

  - **Status**: Dealer status.

  - **Updated date**: Date the dealer was added to the group.

  - **Detail**: Navigates to the dealer's detailed view.

**Action buttons (bottom of the screen)**

- **\[delete\]**: Deletes the dealer group.

  - When deleted, all dealers are unassigned from the group.

- **\[edit\]**: Navigates to the edit screen for the group.

- **\[view list\]**: Returns to the group list screen.
