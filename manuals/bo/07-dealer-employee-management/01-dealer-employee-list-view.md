## Dealer Employee List View

![Dealer Employee List](images/dealer-employee-list.png){width=6.27in}

<!-- TODO: 이미지 갱신 필요 - GIDPDVO-2350 테이블 컬럼 'Partner ID' → 'ID' -->

This is a page where you can create, view, and modify the accounts and information of all users registered in Dealers.

UserNo.: The user\'s No.

ID: The user\'s ID. If the user has no ID, "-" is displayed.

Name(first name/last name): The user\'s name

Job title: The job title assigned to the user

Dealer no.: The number of the dealership to which the account belongs

Dealer name: The name of the dealership to which the account belongs

Zone: Shows the user's assigned dealer zone. If none is assigned, "Unassigned" is displayed.

District: Shows the user's assigned dealer district. If none is assigned, "Unassigned" is displayed.

Updated by: The ID of the user who created or recently modified the account

Updated date: The date the account was created or recently modified

Status: The status value of the account

Active: Account is in active state

Inactive: Account is in inactive state

Detail: Screen to view detailed information of the employee

- Clicking \[Create New\] moves to the screen for creating new dealer employee information.

![Dealer Employee - Search](images/dealer-employee-search.png){width=6.27in}

You can search for employees according to specific conditions.

User Name: You can search by the user\'s name

User No.: You can search by the user\'s user No.

ID: You can search by the user\'s ID

Job title: Select the job title assigned to the user. Multiple selections are possible, and selected items are displayed in the job title area below.

If no **Job** is assigned, you can search by selecting **'None'**.

Status: You can search according to the status of the user account

1.  You can also search using the information of the dealer the user is assigned to.

    - Dealer: You can search by the user\'s Dealer.

    - Zone: You can search by the zone information of the dealer the user is assigned to.

    - District: You can search by the district information of the dealer the user is assigned to. The district field is enabled only after a zone is selected, and by default, all districts are selected.

<!-- -->

1.  \[Reset\] initializes the filter conditions and resets the search results.

2.  \[Search\] displays search results for users that match the set conditions.
