## View Job

- In the **Job Management List** screen, clicking **\[Detail\]** allows you to view the detailed information of the selected job.

![Job Detail](images/job-detail.png){width=6.27in}

**Job Information**

- **Job Code**: The code automatically assigned when the job is created.

- **Job Title**: The name of the job, provided in both **English** and **French**.

- **Description**: A brief explanation of the job role.

- **Status**: The current status of the job. When first created, the status is set to **Active** by default.

**Menu Permission**

- **Displays the list of** menu-specific permissions and Quick Links **mapped to the job.**

- **On the view screen, only menus (e.g., bulletin boards)** with assigned permissions **will be shown.**

<!-- -->

- Change History

![Job - Change History](images/job-change-history.png){width=5.90in}

- If a job has been modified after creation, you can **view its edit history**.

- Clicking **\[See All Changes\]** will open a **pop-up** displaying the full list of changes.

![Change History Popup](images/change-history-popup.png){width=3.81in}

- **Change Date**: The date and time when the change occurred.

- **Change Info**: The specific field or item that was modified.

- **Change Details**: Displays both the **before** and **after** values of the change.

  - Permission Change Format:

  - Changes are displayed in the format: **\[Permission Name -- Bulletin Board Name\]**.

  - If a permission was **added**, it will appear under **After Change** with the permission and bulletin name.

  - If a permission was **removed**, it will appear under **Before Change**.

  - **Updated By**: The employee number of the user who made the change.

<!-- -->

- **Action Buttons**

  - \[View List\]**: Navigates to the** Job List **screen.**

  - \[Edit\]**: Opens the** Edit Job **screen for the selected job.**

    - **If the job is** Super Admin **or** Dealer Principal**, an alert will indicate that** editing is not allowed**.**
