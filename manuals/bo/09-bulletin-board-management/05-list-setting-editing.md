## List Setting Editing

![Editing List setting](images/list-setting-editing-img-1.png){width=5.14in}

- **Order**: You can rearrange the order of **Field Names** by pressing and holding the icon for more than **1 second**, then using **drag & drop** to reorder the fields.

- **Field Name**: When entering edit mode, **default fields** (e.g., Post ID, Title, Date) appear at the top, and **additional attributes** are shown below.\
  The display order for **both** types can be rearranged.

- **Display Setting**:

  - A **toggle switch** is shown for each field, allowing you to set whether it will be displayed on the front-end bulletin board.\
    The toggle follows these rules:

    - For default fields (Post ID, Title, Date): Toggle is always ON and read-only.

    - For additional attributes with Search Filter = ON: Toggle is always ON and read-only.

    - For **additional attributes** with **Required Field = ON**: Toggle is **ON** and **editable**.

    - For additional attributes with Required Field = OFF: Toggle is OFF and editable.

Action Buttons

- **\[Cancel\]**: Clicking this button will show a warning message if there are unsaved changes.\
  Proceeding will discard all unsaved edits.

- **\[Save\]**: Saves the list settings according to the configured **order** and **toggle display status**.

After Saving

- Fields with the toggle set to **ON** will move to the top of the list.

- The **Order** will be displayed as sequential numbers (1, 2, 3, \...).
