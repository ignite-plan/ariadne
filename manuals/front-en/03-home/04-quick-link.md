## Quick Link

- This is a feature that allows users to quickly access frequently visited menus.

- Users can add and delete desired menus individually.

- Clicking on a registered menu in the list will take you to that menu screen.

- Quick Links may be preconfigured according to the user's job.

<!-- -->

- **Using Quick Link on the Home Screen**

- ![Quick Link](images/quick-link-img-1.png){width=2.20in}

- Quick links are provided on the right side of the home screen.

- If no menu has been added yet, the title and settings button are still shown along with the guidance message "Add frequently used menus to Quick Links" and an **\[add quick links\]** button that opens the settings popup.

- All registered Quick link lists are displayed on the screen, and up to 20 can be registered and checked. Adding more than 20 shows the alert "You can add up to 20 items." If a menu name is long, it is displayed with line breaks so the full name is visible.

- Hovering over a menu name for about 1 second displays the full menu path.

- Clicking the **star icon** to the right of the menu name removes it from the quick link list.

  - ![](images/quick-link-img-2.png){width=0.22in} : Status of being added to quick link

  - ![](images/quick-link-img-3.png){width=0.22in} : Status of not being added to quick link

- Pressing the **\[edit\]** button next to the quick link menu creates a popup that manages the entire quick link list. (description below)

- Board you\'ve visited below Quick link displays recently visited menus.

- Clicking the star icon in that list immediately adds it to quick links.

- If the menu is already added to quick links, clicking the icon will remove it from quick links.

![Quick Links on Home Screen](images/quick-links-on-home-screen.png){width=3.48in}

**\
Using Quick Link from Other Screens**

- Clicking the star icon in the GNB opens the Quick links slide panel on the right side of the screen. The panel can be accessed from any screen within Dealers by clicking this icon.

- The panel is closed by clicking the GNB star icon again, clicking the X button on the panel, or clicking outside the panel.

- Clicking a menu name in the list takes you to that menu.

- Clicking the star icon removes it from Quick link.

- Clicking the **\[Add Quick Links\]** button at the bottom creates a popup that manages the entire quick link list (description below)

![Quick Link Panel](images/quick-link-panel.png){width=1.99in}

**Quick Link Settings**

- This is a popup that appears when you click edit next to Quick link on the home screen, or click **\[Add Quick links\]** at the bottom of the Quick link sheet.



![Quick Link](images/quick-link.png){width=4.2in}


Quick Link Setting Popup

- Menu List shows the entire menu tree the user has permission to access, organized by depth. Each level can be collapsed or expanded, and the list is fully expanded by default. Directory-type menus do not show a bookmark icon and cannot be added to Quick Links.

- Using the search box at the top, you can quickly find a menu by searching part of its name; matching keywords are highlighted and parent menus of a match are also shown. Clicking the X button resets the search.

- A guide banner with the message "Only menus linked to a page can be added as Quick Links." is displayed at the top of the Menu List, below the search box. The info icon next to the message is a simple icon, not a tooltip. Directory-type menus do not show a star icon and cannot be added.

- The banner stays fixed at the top, so it remains visible while scrolling the menu list.

- Clicking the **x** button on the banner closes it, and it is not displayed again once closed. The closed state is saved in the browser's local storage per dealer, so the banner is displayed the first time the same employee accesses a different dealer.


![Quick Link](images/quick-link-2.png){width=3.4in}


- Add to **Quick Links** is a list of menus added by the user. The first added menu is at the top, and clicking the six-dot drag handle icon on the left allows you to change the order as desired.

- Up to 20 can be added to quick links. Adding more than 20 shows the alert "You can add up to 20 items."

- Pressing the **\[cancel\]** button closes the window without saving the changes made so far. Pressing the **\[save\]** button saves the changes and the new quick link list is reflected in all quick link lists.

**Rename Quick Link**

![Rename Quick Link](images/rename-quick-link.png){width=3.60in}

- Hovering over a Quick Link item displays a pencil icon. Clicking it opens the "Rename Quick Link" modal.

- If no custom name has been saved, the Name field placeholder displays the original menu name (following the language setting). If a custom name exists, it is pre-filled.

- Maximum 50 characters. Numbers and special characters are allowed, and there are no banned words. A character counter is provided.

- Clearing the field via the X button and losing focus restores the original menu name as text.

- The menu path is displayed below the text field, up to the menu's own depth (maximum 5 depths).

- Cancel closes the modal without saving. Save is always enabled.

**After Saving**

- The custom name is reflected in the Quick Links area, Quick Links slide panel, and \"Board you\'ve visited\" (for menus already added to Quick Links).


- Not reflected in the Menu List within Quick Link Settings, GNB/SNB, or \"Board you\'ve visited\" for menus not added to Quick Links.

- A custom name can duplicate another menu's original name or custom name; duplicate registration is allowed.

- Custom names are applied per dealer and are not synced across dealers for multi-dealer users.

- If a menu is removed from Quick Links and re-added, the custom name is reset.
