**Login method**

- Go to <https://dealers.hyundai-corp.io/ca/> to access the first screen.

- You will be directed to the HMG Partner login screen.

- Select Corporation Code and enter hacc in the Corporate Code field.

- Log in using your HMG Partner ID and password.

![Login Screen](images/login-screen.png){width=4.73in}

- When accessing Dealers for the first time, you will be asked to agree to the HMG Partner ID service terms.

- After that, you will be directed to the Dealers Service Terms and Personal Information Consent screen.

![Service Agreement Screen](images/service-agreement-screen.png){width=6.79in}

- [You must agree to the required items and press the \[Continue\] button to use the service.]{.mark}

- If you belong to two or more dealerships, including Hyundai/Genesis brands, you will be directed to a screen where you can select which dealership to access.![](images/login-and-logout-img-1.png){width=6.18in}

Dealer Selection Screen

- On the dealer selection screen, you can view both the brand and the dealer name for each affiliated dealership.

- If you can access a dealer, "Available" will appear. If access is not allowed, you will see "Access Denied" and cannot log in as a member of that dealer.

- When accessing a brand for the first time, you must agree to the service agreement on the agreement screen before using the service.

**Logout Method**

- User logout instructions:

  - Click on the profile image area at the top left of the screen.

  - An Account sheet will appear.

  - Select Logout from this sheet.



![](images/image.png){width=6.27in}



- Automatic logout instructions:

  - In accordance with security policy, Dealers will automatically log you out if no activity is detected on the site for 60 minutes.

  - After 55 minutes of inactivity, a popup will appear notifying you that logout will occur in 5 minutes.

  - If inactivity is detected for 60 minutes, automatic logout will be initiated.

  - If a user returns to the Dealers screen after 60 minutes have passed, they will be automatically logged out.

![Session End Pop-up](images/session-end-pop-up.png){width=5.88in}
