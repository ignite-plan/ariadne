- HMG-notice is a system used for the purpose of providing a platform-based function for managing announcement content through the **\"Common Notice System (hmg-Admin)\"**

- It provides APIs to manage content such as FAQs, terms and conditions, notices, and notifications (pop-ups, etc.) so that they can be used appropriately for the Dealers service.
