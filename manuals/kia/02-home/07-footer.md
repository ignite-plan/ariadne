## Footer

- In the footer area at the very bottom of the Dealers homepage, you can check Service term, privacy policy, FAQ, Cookie policy and User Manual content.

**Service Term**

- 	Clicking on Service Term allows you to check the latest service terms.
  
- When you click Service Term, the Service Term page will open in a new tab.

- Clicking on the select box in the upper right provides previous versions of the service terms.

 

![Service Term](images/service-term.png){width=6.27in}




**Privacy Policy**

- Clicking on **Privacy policy** allows you to check the latest personal information policy.

- When you click Privacy Policy, the Privacy Policy page will open in a new tab.

- Clicking on the select box in the upper right provides previous versions of the personal information policy.

  ![Privacy policy](images/privacy-policy.png){width=6.09in height=2.78in}

**FAQ**

- Clicking on FAQ allows you to check **frequently asked questions.**

- When you click FAQ, the FAQ page will open in a new tab.

- The left area provides the major categories of questions.

- When you select a category, appropriate questions are displayed in the right area.

- You can select a second category in the filter at the top.

  ![FAQ](images/faq.png){width=6.40in}

- FAQ categories are displayed up to a maximum of 3.

- If there is no relevant content, it will not be displayed.

- Clicking on a **question title** allows you to check the detailed content.

- Clicking an attached file opens a preview, and the download icon allows you to save the file.

- A **\"Frequently asked\"** badge is provided for frequently asked questions. ![](images/footer-img-1.png){width=1.44in}

**Cookie policy**

- Clicking on **Cookie policy** allows you to check the cookie policy content.

- When you click Cookie Policy, the Cookie Policy page will open in a new tab.

- Clicking on the select box in the upper right allows you to check the content of previous versions of the policy.

- Clicking the **\[cookie settings\]** button at the top creates a cookie settings popup.

    ![Cookie Policy](images/cookie-policy.png){width=5.72in}

- In the popup, you can reset and save the cookie values that you individually consent to.\

    ![Cookie Settings](images/footer-img-2.png){width=3.65in}


**User Manual**

- Clicking on User Manual allows you to check the user manual content.

- When you click User Manual, the FAQ screen with user manual-related content will open in a new tab.
