- **Keyword Search**

- Search results matching the entered search keywords are displayed. If there are attachments, they are also displayed.

- Clicking on a post takes you to the post detail screen.



![](images/image.png){width=4.2in}





![](images/image-2.png){width=4.2in}


- **Sort Search Results**

- Search results can be sorted by specific conditions.

  - **Relevant:** By keyword accuracy

  - **Most recent:** By latest

- ![](images/search-result-img-2.png){width=2.13in}

Sort Search Result by condition1

- ![](images/search-result-img-3.png){width=1.68in}

Sort Search Result by condition2

- **anytime:** Entire period

- **past week:** Past 1 week

- **past month:** Past 1 month

- **past year:** Past 1 year

- **custom range:** When clicked, the date range function is displayed, allowing you to search by entering a desired period



![](images/image-4.png){width=3.4in}



- Once you have searched, you can filter the results by selecting one or more boards. Only posts within the selected boards are displayed. If no board is selected, all board results are shown by default.

- ![](images/search-result-img-4.png){width=2.31in}

Select Board

- Search results for posts with attachments or thumbnails are displayed as follows.



![](images/image-5.png){width=3.4in}



- Clicking on an attachment allows you to view a **preview.**



![](images/image-6.png){width=3.4in}



- Clicking on the **post title, body, thumbnail**, etc. takes you to the post detail screen.

- Clicking the **\[Load more result\]** button at the bottom of the search results loads 20 more search results at a time, and the button is not displayed if there are no more search results.
