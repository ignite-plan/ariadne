## Menu List View

- You can view registered menus in the Menu List and create/edit/delete/move new menus.

- Users with permissions will see the \[+ Group Addition\] button and can create menus.

- You can search for and select the desired Menu name.

- If no menu is selected, a menu selection guide message is displayed, and when a specific menu is selected, you can view the menu detail screen on the right.

![Menu List -- initial view](images/menu-list-initial-view.png){width=5.37in}

- When hovering over a created menu, you can create sub-menus or delete that menu.\

  ![Menu and sub-menu - hovering status](images/menu-list-view-img-1.png){width=5.84in}


- You can move menus within the same menu level by clicking and holding for 1 second, then drag & drop.\

  ![Menu re-ordering](images/menu-list-view-img-2.png){width=1.99in}


**Menu Search & Results**

- You can search for Menu names in the menu search box. When you type words in the search box, real-time keyword search (like search) is available.

- Menu search conditions:

  - All hierarchies of menus matching the search criteria are displayed.

  - Keywords matching the search criteria are highlighted with color.

  - Clicking the \[x\] button on the right after entering search terms deletes all keywords and returns to the initial state.

  - If there are no search results, a \"no search results\" message is displayed.

  ![Menu List - Search](images/menu-list-search.png){width=6.26in}
