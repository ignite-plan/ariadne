## Dealer distribution group List View

![Dealer Distribution Group List](images/dealer-distribution-group-list.png){width=6.26in}

- This screen allows you to create, modify, delete, and view dealer distribution groups for managing dealers.

- You can view existing dealer groups.

  - **Name**: Name of the dealer group.

  - **Description**: Description of the dealer group.

  - **Dealers**: Number of dealers belonging to the group.

  - **Updated by**: ID of the user who created or last updated the group.

  - **Updated date**: Date when the dealer group was created or last updated.

  - **Detail**: Navigates to the detailed view of the dealer group.

- Click the **\[create new\]** button on the list view to navigate to the new group creation screen.
