## Quick Link

- This is a feature that allows users to quickly access frequently visited menus.

- Users can add and delete desired menus individually.

- Clicking on a registered menu in the list will take you to that menu screen.

- Quick Links may be preconfigured according to the user's job.

**Using Quick Link on the Home Screen**

![Quick Link](images/quick-link-2.png){width=2.83in}

- Quick links are provided on the right side of the home screen.

- All registered Quick link lists are displayed on the screen, and up to 20 can be registered and checked. If a menu name is long, it is displayed with line breaks so the full name is visible.

- Hovering over a menu name displays the full menu path.

- Clicking the **star icon** to the right of the menu name removes it from the quick link list.

  - ![](images/quick-link-img-1.png){width=0.22in} : Status of being added to quick link

  - ![](images/quick-link-img-2.png){width=0.22in} : Status of not being added to quick link

- Pressing the **\[edit\]** button next to the quick link menu creates a popup that manages the entire quick link list. (description below)

- Board you\'ve visited below Quick link displays recently visited menus.

- Clicking the star icon in that list immediately adds it to quick links.

- If the menu is already added to quick links, clicking the icon will remove it from quick links.

![Quick Links on Home Screen](images/quick-links-on-home-screen.png){width=3.65in}

Using Quick Link from Other Screens**

- Clicking the star icon in the upper right area of the Dealers screen creates a Quick links list on the right.

- This list can be accessed from any screen within Dealers by clicking the **star icon** at the top.

- Clicking a menu name in the list takes you to that menu.

- Clicking the star icon removes it from Quick link.

- Clicking the **\[Add Quick Links\]** button at the bottom creates a popup that manages the entire quick link list (description below)

![Quick Link Panel](images/quick-link-panel.png){width=2.05in}

**Quick Link Settings**

- This is a popup that appears when you click edit next to Quick link on the home screen, or click **\[Add Quick links\]** at the bottom of the Quick link sheet. ![](images/quick-link-img-3.png){width=5.56in}

Quick Link Setting Popup

- Menu List shows the list of menus displayed on the Dealers screen according to the user\'s permissions.

- Using the search box at the top, you can quickly find a menu by searching for its name.

- Add to **Quick Links** is a list of menus added by the user. The first added menu is at the top, and clicking the six-dot drag handle icon on the left allows you to change the order as desired.

- Up to 20 can be added to quick links.

- Pressing the **\[cancel\]** button closes the window without saving the changes made so far. Pressing the **\[save\]** button saves the changes and the new quick link list is reflected in all quick link lists.

**Rename Quick Link**

![Rename Quick Link](images/rename-quick-link.png){width=3.60in}

- Hovering over a Quick Link item displays a pencil icon. Clicking it opens the Rename Quick Link modal.

- If no custom name has been saved, the field placeholder displays the original menu name. If a custom name exists, it is pre-filled.

- Maximum 50 characters. Numbers and special characters are allowed. A character counter is provided.

- Clearing the field via the X button and losing focus restores the original menu name as text.

- The full menu path is displayed below the text field.

- Cancel closes the modal without saving. Save is always enabled.

**After Saving**

- The custom name is reflected in the Quick Links area, Quick Links slide panel, and \"Board you\'ve visited\" (for menus added to Quick Links).

- Not reflected in the Menu List within Quick Link Settings, GNB/SNB, or \"Board you\'ve visited\" for menus not added to Quick Links.

- Duplicate custom names are allowed across different menus.

- Custom names are applied per dealer and are not synced across dealers for multi-dealer users.

- If a menu is removed from Quick Links and re-added, the custom name is reset.
