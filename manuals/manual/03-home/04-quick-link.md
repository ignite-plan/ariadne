## Quick Link

- This is a feature that allows users to quickly access frequently visited menus.

- Users can add and delete desired menus individually.

- A menu is removed from the list automatically when the user loses permission for it or when the menu is deactivated or deleted.

- Clicking on a registered menu in the list will take you to that menu screen.

- Quick Links may be preconfigured according to the user's job.

**Using Quick Link on the Home Screen**

![Quick Link](images/quick-link-2.png){width=2.83in}

- Quick links are provided on the right side of the home screen.

- All registered Quick link lists are displayed on the screen, and up to 20 can be registered and checked. If a menu name is long, it is displayed with line breaks so the full name is visible.

- Hovering over a menu name for 1 second or more displays a tooltip with the full menu path.

- Clicking the **star icon** to the right of the menu name removes it from the quick link list.

  - ![](images/quick-link-img-1.png){width=0.22in} : Status of being added to quick link

  - ![](images/quick-link-img-2.png){width=0.22in} : Status of not being added to quick link

- Pressing the **\[edit\]** button next to the quick link menu moves to the Quick Links edit screen, which manages the entire quick link list. (description below)

- If there are no registered Quick Links, the message "Add frequently used menus to Quick Link." and the **\[Add Quick Links\]** button are displayed. The button moves to the edit screen.

- Boards you\'ve visited below Quick link displays recently visited menus (1 to 5 items). This area is displayed only when there is at least one visited menu.

- Clicking the star icon in that list immediately adds it to quick links.

- If the menu is already added to quick links, clicking the icon will remove it from quick links.

- As in the Quick Links area, a long menu name is displayed with line breaks, and hovering over it for 1 second or more displays the full menu path.

![Quick Links on Home Screen](images/quick-links-on-home-screen.png){width=3.65in}

Using Quick Link from Other Screens**

- Clicking the **Quick Links** button in the GNB opens the Quick links slide on the right. Hovering over the icon displays the Quick Links label.

- This slide can be accessed from any screen within Dealers by clicking the button in the GNB.

- The slide title is Quick links, and it has an **\[add quick link\]** button, which opens the settings popup, and an **\[X\]** button.

- Menu titles are displayed in the user\'s language. If there are more menus than fit on the screen, the list scrolls.

- Hovering over a menu name displays a tooltip with the full menu path.

- Clicking a menu name in the list takes you to that menu.

- Clicking the star icon immediately removes the menu from Quick link.

- To close the slide, click the GNB button again, click the **\[X\]** button, or click outside the slide.

- If the list is empty, the message "Add frequently used menus to Quick Links" and the **\[add quick links\]** button are displayed. Clicking the button opens the popup that manages the entire quick link list (description below)

**Quick Link Settings**


- This is a popup titled "Quick links Settings" that appears when you click edit next to Quick link on the home screen, or click the **\[add quick link\]** / **\[add quick links\]** button or edit in the Quick link slide (the slide closes when the popup opens). ![](images/quick-link-img-3.png){width=5.56in}

Quick Link Setting Popup

- Menu List shows all menus the user has permission for, by depth. If there are more menus than fit on the screen, the list scrolls.

- Menus with sub-menus can be collapsed and expanded, and all are expanded by default. Menus without sub-menus have no collapse icon.

- Menus that are not added show an empty star icon. Directory type menus have no star icon and cannot be added.

- A guide banner "Only menus linked to a page can be added as Quick Links." is displayed at the top. Closing it with the X button prevents it from appearing again. It is stored in local storage per dealer, so the banner appears again when the same user first accesses a different dealer.

- Using the search box at the top, you can quickly find a menu by searching for part of its name. Search runs in real time, matching keywords are highlighted, and all parent menus are displayed. Clicking X resets the search.

- Add to **Quick Links** is a list of menus added by the user. Initially it is empty and displays "Choose menu items on the left to add as quick links". Clicking a star changes the icon color, and the most recently added menu is stacked at the bottom regardless of depth. Clicking a filled star again removes the menu, and its star in the Menu List returns to empty.

- To change the order, drag the hamburger handle on the left. Hovering over the handle changes the cursor to show it can be moved, and the selected item area changes color and displays a pencil icon.

- Up to 20 can be added to quick links. Adding a 21st shows the alert "You can add up to 20 items".

- Pressing the **\[cancel\]** button closes the window without saving the changes made so far. Pressing the **\[save\]** button closes the window, and all changes are saved and reflected in all quick link lists. No completion alert or save confirmation modal is displayed.

**Rename Quick Link**

![Rename Quick Link](images/rename-quick-link.png){width=3.60in}

- Hovering over a Quick Link item displays a pencil icon. Clicking it opens the Rename Quick Link modal.

- If no custom name has been saved, the field placeholder displays the original menu name. If a custom name exists, it is pre-filled.

- Maximum 50 characters. Numbers and special characters are allowed, and there are no prohibited words. A character counter and an X button (clear all) are provided.

- Clearing the field via the X button displays the original menu name as the placeholder.

- The full menu path is displayed below the text field (up to 3 depths for a 3-depth menu).

- The area behind the modal is dimmed.

- Cancel closes the modal without saving. Save is always enabled.

**After Saving**

- The custom name is reflected in the Quick Links area, Quick Links slide panel, and \"Board you\'ve visited\" (for menus added to Quick Links).

- Not reflected in the Menu List within Quick Link Settings, GNB/SNB, or \"Board you\'ve visited\" for menus not added to Quick Links.

- Duplicate names are allowed, including names identical to existing menu names or other custom names.

- Custom names are applied per dealer and are not synced across dealers for multi-dealer users.

- If a menu is removed from Quick Links and re-added, the custom name is reset.
