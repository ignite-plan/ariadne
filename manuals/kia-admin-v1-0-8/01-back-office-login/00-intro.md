 **Dealers Admin User Manual**


- While connected to the VPN, access the URL: [https://dealers-admin.kia-corp.io/ca](https://dealers-admin.hyundai-corp.io/ca)

![Login screen](images/login-screen.png){width=6.26in}

On the login screen, proceed with the following steps:

- Select your **region**

- Select your **company**

- Enter your **ID and password**

- Click **Login** to sign in

- Select a project -- **Kia Dealers_BO**

![HMG Admin](images/hmg-admin.png){width=8.26in}

**Back Office Main Screen**

![HMG Admin Head area](images/hmg-admin-head-area.png){width=6.26in}

- The project name is displayed at the top-right corner of the Back Office.

- To the right of the project name, the current user\'s Back Office role is shown.

- If the user has multiple roles, selecting one will display the menus and features associated with that role.

- Click Request to add new role to submit a request for additional role permissions.

![HMG Admin role](images/hmg-admin-role.png){width=2.60in}

- The remaining time of the **login session** is displayed. If there is no activity for 60 minutes, the session will be automatically logged out. Click **Login extension** to extend the session by another 60 minutes.

- The current admin\'s **language setting** is displayed. The Back Office supports **English and French** by default.

- The **affiliation and name** of the logged-in user are displayed.

- A **Settings** button is available, where the user can log out.
