## Holding Company Detail View

![Holding Company Detail](images/holding-company-detail.png){width=6.26in}

- Selecting **Detail** from the list view opens the holding company\'s detailed view screen.

**Holding company information**

- **Company name**: Name of the holding company.

- **Name of company representative**: Name of the representative.

- **Dealers**: Number of affiliated dealers.

- **Dealer status**: Number of dealers by status.

**Affiliate Dealer List**

- Shows the list of dealers affiliated with the holding company.

  - **No**: Sequence number.

  - **Dealer name**: Name of the dealer.

  - **Dealer no.**: Dealer number.

  - **Status**: Dealer's status.

  - **Updated date**: Date the dealer was affiliated with the holding company.

  - **Detail**: Navigates to the dealer\'s detailed view.

**Action Buttons**

- **\[delete\]**: Deletes the holding company.

  - If deleted, all affiliated dealers will become unassigned from any holding company.

- **\[edit\]**: Opens the edit screen for the holding company.

- **\[view list\]**: Returns to the holding company list view.
