## Dealer Distribution Group Creation

This screen is for creating a new dealer distribution group.

![Creation Group](images/creation-group.png){width=5.19in}

**Dealer group information**

- **Dealer distribution group Name**:

  - Required field.

  - Up to 20 characters.

  - Duplicate names are not allowed.

- **Description:**

  - Optional field.

  - Up to 50 characters.

  - **Dealer list**

  - Displays the full list of available dealers.

  - You can select dealers to include in the group.

  - Each dealer entry shows: name, dealer number, and status.

  - Dealers are displayed in the following status priority: Active, Under Terminated, Inactive, Terminated and then sorted alphabetically by dealer name.

  - You can search dealers by name in both the Dealer list and Selected dealers.

    - When a dealer is checked in the Dealer list, they appear in the Selected dealers section.

    - Unchecking a dealer or clicking the x button in Selected dealers removes them from the selection.
