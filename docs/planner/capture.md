# 화면 캡처 (STG)

[← 기획자 사용법](README.md)

화면이 바뀌었을 때 매뉴얼 이미지를 STG에서 새로 찍습니다. 캡처 대상 주소와 화면 크기는 매뉴얼마다 정해져 있습니다(설정 → 매뉴얼).

## 캡처하기

1. 위쪽 **캡처**를 누릅니다.
2. 처음이거나 세션이 만료되었으면 **로그인**합니다. 아래 [STG 로그인](#stg-로그인)을 봅니다.
3. **지금 화면** 또는 **전체**에서 캡처할 이미지를 고르고 **N장 캡처**를 누릅니다.
4. 바뀐 이미지만 **지금 매뉴얼 / 새로 찍은 화면**으로 나란히 나옵니다. 반영할 것만 체크하고 **선택한 N장 반영**을 누릅니다.

> [!NOTE]
> 캡처는 화면을 열고 찍기만 합니다. 저장, 삭제 같은 버튼은 누르지 않습니다.

| 이럴 때 | 이렇게 |
|---|---|
| `수동` 표시가 붙은 이미지 | 자동으로 찍지 않는 이미지입니다(아이콘을 잘라 낸 이미지 등). 직접 캡처해 편집기에 붙여 넣습니다 |
| "이 화면에는 자동 캡처가 아직 없습니다" | 아래 [자동 캡처가 없는 화면](#자동-캡처가-없는-화면) |

## 자동 캡처가 없는 화면

자동 캡처는 화면마다 "STG의 어느 주소를 열고, 무엇을 누르고, 어디를 찍는지"(캡처 정의, `shots.ts`)가 있어야 합니다. **전체**에서 "자동 캡처가 있는 화면 N / 전체"로 얼마나 등록됐는지 볼 수 있습니다.

정의가 없는 화면을 열고 캡처하면 **[Claude로 이 화면 캡처 정의 만들기]**와 **[이 장 전체]** 버튼이 나옵니다.

1. 버튼을 누르면 Claude 패널이 열립니다. **캡처 정의 만들기 시작**을 누릅니다.
2. Claude가 화면의 이미지마다 STG에서 같은 화면(팝업, 탭, 입력 상태)을 열어 찍어 보고, 매뉴얼 이미지와 같은 화면이면 캡처 방법을 등록합니다. 화면을 3개씩 동시에 확인합니다.
3. 끝나면 **[닫고 캡처 열기]** → 새로 등록된 이미지를 골라 **N장 캡처** → 비교해서 반영할 것만 **반영**합니다.
4. **변경** 탭의 `자동 캡처 정의 (shots.ts)`를 제출하면 다른 사람도 같은 정의로 캡처합니다.

- 본문과 매뉴얼 이미지는 바꾸지 않습니다. 기획서(Confluence)도 쓰지 않아 최신화보다 빠르고 사용량도 적습니다.
- 다시 만들 수 없는 이미지(잘라 낸 아이콘, 저장한 뒤에만 보이는 화면)는 등록하지 않고 결과에 이유를 남깁니다. 그런 이미지는 직접 캡처해 편집기에 붙여 넣습니다(⌘V).
- 최신화처럼 도는 중에 다른 화면이나 장을 **대기에 추가**할 수 있습니다.
- [Claude로 최신화](claude-features.md#claude로-최신화)도 처음 최신화하는 화면의 캡처 정의를 채웁니다. 본문까지 맞출 때는 최신화를 씁니다.

## STG 로그인

1. 캡처 화면에서 **로그인**을 누릅니다.
2. Chrome 창이 열리면 STG에 로그인합니다(MFA 포함).
3. STG 화면이 보이면 앱에서 **로그인 완료**를 누릅니다.

- 로그인 세션은 매뉴얼마다 따로 둔 Chrome 프로필에 남고, **캡처, 가이드 영상, Claude 작업이 같이 씁니다.**
- 로그인 박스의 **확인**은 STG를 실제로 열어 세션이 살아 있는지 봅니다. 만료됐으면 "STG 로그인 필요"로 바뀌니 **다시 로그인**을 누릅니다.
- Claude 작업은 시작할 때 세션을 자동으로 확인합니다.

## 다른 작업과 함께 돌리기

| 함께 돌릴 수 있는 작업 | 혼자만 돌 수 있는 작업 |
|---|---|
| Claude 작업, 영상 만들기, 캡처, 세션 확인 | 로그인, 영상 미리보기, STG에서 기록 |
| 앱이 로그인 프로필로 화면 없는 Chrome을 하나 띄우고 작업마다 탭을 나눠 씁니다. 같은 로그인을 쓰므로 서로 로그아웃시키지 않습니다 | 화면이 보이는 Chrome을 따로 띄우므로 다른 STG 작업이 없을 때만 할 수 있습니다. 버튼이 꺼져 있으면 마우스를 올려 어떤 작업 때문인지 확인합니다 |

- Claude 작업은 실행 중에 **숨기기**로 패널을 접을 수 있습니다. 위쪽 작업 표시(예: `Claude 최신화 · 3:12`, `영상 만들기 · 장면 2/5`)를 누르면 다시 열리고, 끝나면 알림이 뜹니다.
- Claude가 고치는 화면과 영상은 끝날 때까지 편집이 막히고, Claude 작업 중에는 제출할 수 없습니다.

> [!TIP]
> 같은 BO 계정 설정(브라우저에 저장되는 필터, 컬럼 등)은 탭끼리 공유됩니다. 영상은 첫 장면에서 화면을 직접 열고 필요한 필터를 맞추게 쓰는 것이 안전합니다.
