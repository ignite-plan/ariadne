## 문장 고치기

1. 왼쪽 **목차**에서 화면을 고릅니다. **화면 찾기**로 검색할 수 있습니다.
2. 가운데 편집기에서 고칩니다. 오른쪽 미리보기가 Word와 같은 모양으로 바로 바뀝니다.
3. 입력을 멈추면 자동 저장됩니다(`저장됨`). ⌘S로 바로 저장할 수도 있습니다.

### 툴바

| 버튼 | 넣는 것 | 결과 |
|---|---|---|
| **B** | `**Label**` | 항목 이름 (굵게) |
| **[ ]** | `**\[Button\]**` | 버튼 이름 `[Save]` |
| • / ⇥ | `- ` / 들여쓰기 | 목록 / 하위 목록 |
| 🖼 | 이미지 | 아래 [이미지 넣기](#이미지-넣기) |
| 형광펜 | `[글자]{.mark}` | 선택한 글자에 노란 형광펜 (Word 원본과 같은 노랑). 형광펜 안에서 다시 누르면 해제. 줄 전체를 골라도 목록 기호(`- `)는 밖에 두고, 굵게·버튼 표기 중간에 걸리면 표기 전체를 감쌉니다 |
| 가운데 정렬 | `{… align=center}` | 커서가 있는 줄의 이미지를 Word에서 가운데로. 다시 누르면 해제 |
| ⚑ | `<!-- TODO: … -->` | 확인이 필요한 메모. Word에는 나오지 않습니다 |
| 🔍 | | 찾기·바꾸기 (아래) |
| ↶ ↷ | | 되돌리기 / 다시 실행 |

### 찾기·바꾸기 (지금 화면 안)

**⌘F**(또는 툴바 🔍)로 찾기, **⌥⌘F**로 바꿀 말 칸이 바로 열립니다. 지금 열린 화면 하나 안에서만 찾고 바꿉니다.

- 찾을 말을 입력하면 편집기에 찾은 곳이 파랗게 표시되고 `3 / 12`처럼 몇 번째인지 보입니다. **Enter**(또는 ↓)로 다음, **⇧Enter**(또는 ↑)로 이전, **Esc**로 닫습니다.
- **바꾸기**는 지금 찾은 곳 하나를 바꾸고 다음으로, **모두 바꾸기**는 이 화면에서 찾은 곳을 모두 바꿉니다. **↶**(⌘Z) 한 번으로 되돌릴 수 있습니다.
- **대소문자**를 켜면 대소문자가 같은 것만, **단어 단위**를 켜면 단어 전체가 같은 것만 찾습니다. `**`, `[`, `.` 같은 기호도 글자 그대로 찾습니다.
- 화면 제목(목차 이름)은 본문이 아니라서 바뀌지 않습니다. 이미지 설명(caption)은 본문이라 함께 바뀝니다.
- Claude가 고치는 중인 화면에서는 찾기만 됩니다.

> [!TIP]
> 편집기 안의 회색 칩(`전체 6.27in`, `팝업 4.2in · 가운데`)은 이미지가 Word에 들어갈 크기와 정렬입니다.
> - 크기를 바꾸려면 이미지를 지우고 다시 넣습니다.
> - 가운데 정렬은 툴바 버튼이나 이미지 넣기 창의 **가운데 정렬**로 켭니다. 켜지 않은 이미지는 캡션이 있으면 가운데, 없으면 왼쪽으로 들어갑니다.

Word 원본을 가져오면 본문의 노란 형광펜이 그대로 남습니다(제목과 이미지 캡션 안의 형광펜은 뺍니다).

## 이미지 넣기

| 방법 | 하는 법 |
|---|---|
| 새 스크린샷 | 편집기에 붙여 넣거나(⌘V) 파일을 끌어 놓습니다. 설명(caption, 영어)과 크기를 고르고 **넣기** |
| 있는 이미지 | 툴바 🖼 → **있는 이미지**에서 검색해 고릅니다. 두 번 누르면 바로 들어갑니다 |

| 크기 | 너비 |
|---|---|
| 전체 화면 | 6.27in |
| 팝업 | 4.2in |
| 작은 팝업 | 3.4in |
| 아이콘 | 0.24in (문장 안에 들어감) |

PNG가 아닌 이미지는 PNG로 바꿔 저장합니다.

## 화면(섹션) 추가, 삭제, 순서

| 하고 싶은 일 | 하는 법 |
|---|---|
| 추가 | 목차 아래 **새 화면** 또는 장 이름 옆 **+** → **빈 화면 직접 쓰기** → 장과 화면 이름(영어). 새 장은 원하는 위치(예: 8장)에 넣을 수 있습니다 |
| 삭제 | 목차에서 화면에 마우스를 올리고 🗑. 제출 전이면 **변경** 탭에서 되돌릴 수 있습니다 |
| 순서 바꾸기 | 목차에서 장이나 화면을 끌어 다른 줄에 놓습니다. 장 번호(폴더 번호)는 자동으로 다시 매겨집니다 |

- 화면은 같은 장 안에서만 옮길 수 있고, 장 소개는 맨 앞에 고정입니다.
- 새 메뉴를 Claude로 쓰려면 [Claude로 초안 만들기](claude-features.md#claude로-초안-만들기)를 씁니다.

## 변경 보기

**변경** 탭에서 화면 옆 ⑂를 누르면 마지막으로 제출된 내용과 지금 내용을 줄 단위로 비교합니다. 빨간 줄은 지운 것, 초록 줄은 추가한 것입니다.

> [!NOTE]
> Claude가 고친 화면은 편집 화면에서 바로 [Claude 변경 표시](claude-features.md#claude-변경-검토)로도 볼 수 있습니다. 변경 보기는 내 수정과 Claude 수정을 합쳐 제출 전 상태를 봅니다.

## Word 만들기

### 만들기 전에 전체 보기

오른쪽 미리보기 위의 **이 화면 | 이 장 | 전체**로 보는 범위를 바꿉니다.

| 범위 | 보이는 것 |
|---|---|
| 이 화면 | 지금 화면만. TODO도 노란 상자로 보입니다 |
| 이 장 | 지금 장의 화면을 Word 순서대로 이어서 |
| 전체 | 매뉴얼 전체를 Word와 같은 순서·내용으로 (장 제목 포함) |

- **이 장**과 **전체**는 Word와 같은 내용이라 TODO가 보이지 않습니다.
- 지금 편집 중인 화면은 왼쪽 테두리로 강조되고, 왼쪽에서 고치는 대로 바로 바뀝니다.
- 다른 화면에 마우스를 올리면 **이 화면 편집**이 나오고, 누르면 그 화면이 편집기에 열립니다.
- Word에 `**`나 `{.mark}`가 글자로 나올 곳이 있으면 빨갛게 표시되고, 위쪽 **Word 표기 문제 N**을 누르면 그 화면으로 갑니다.
- **Word 만들기 → 만들기 전 전체 보기**를 누르면 미리보기만 넓게, 전체 범위로 바로 바뀝니다.

### 만들기

위쪽 **Word 만들기**에서 **전체 매뉴얼** 또는 **지금 장만**을 고릅니다. 완료 알림의 **열기**를 누르면 Word로 열립니다. 파일은 작업 폴더의 `dist/`에 생깁니다.

> [!WARNING]
> Word 파일을 직접 고치면 다음에 만들 때 사라집니다. 고칠 내용은 항상 앱에서 고칩니다.

- TODO 메모는 Word에 들어가지 않습니다(미리보기와 TODO 탭에서만 보입니다).
- 굵게·형광펜 표기가 깨져 Word에 `**`나 `{.mark}`가 글자로 그대로 나오는 화면이 있으면, 완료 알림에 그 화면 이름이 나옵니다. 그 화면의 굵게(`**…**`)와 형광펜(`[…]{.mark}`) 괄호가 짝이 맞는지 고친 뒤 다시 만듭니다. 자세한 위치는 로그(설정 → 정보)에 남습니다.

## 제출

1. 위쪽 **제출**을 누릅니다(숫자는 변경 수).
2. 바뀐 화면 목록을 확인하고, **무엇을 바꿨나요**를 한 줄로 고칩니다(자동으로 채워집니다).
3. **제출하고 바로 반영**을 누르면 매뉴얼 원본(GitHub)에 올라갑니다.

- 다른 사람이 먼저 올린 변경은 자동으로 합칩니다.
- 같은 문장을 동시에 고쳐 합칠 수 없으면, 앱이 PR을 만들어 개발자에게 넘깁니다. 내 수정은 화면에 그대로 남아 있으니 **같은 수정을 다시 하지 말고** 이어서 작업하거나 기다립니다. 개발자가 PR을 합치면 다음 동기화 때 최신 상태로 돌아옵니다. 합치기 전에 다시 제출하면 이전 PR 내용까지 담은 새 PR이 만들어집니다.
- 바로 반영하지 않고 개발자 검토를 거치려면 **설정 → 일반 → 제출 방식**을 **검토 후 반영 (PR)** 으로 바꿉니다.
- Claude 작업이 도는 동안에는 제출할 수 없습니다.

> [!TIP]
> 충돌을 줄이려면 같은 화면은 한 사람이 맡고, 고친 뒤 바로 제출합니다.

## 내 PC에 기록만 (제출 전 저장점)

제출 창의 **[내 PC에 기록만]**은 원격(GitHub)에 올리지 않고, 지금까지 고친 내용을 내 PC의 이력(커밋)으로 남깁니다. 아직 제출할 때가 아니지만 고친 내용이 날아가지 않게 해 두고 싶을 때 씁니다.

- 오프라인에서도 됩니다. **무엇을 바꿨나요** 한 줄도 같이 남습니다.
- 기록한 변경도 제출 전이라 **변경** 탭과 제출 숫자에 그대로 보입니다. 위쪽 동기화 표시에 `내 PC 기록 N`이 보입니다.
- 나중에 **제출**하면 그동안의 기록과 새 변경을 한 커밋으로 올립니다. 커밋 설명에 기록들이 함께 적힙니다.
- **Claude 초안·최신화·캡처 정의·영상 작업을 시작할 때 자동으로 기록합니다.** Claude가 파일을 고치기 전 상태가 이력에 남습니다(고친 것이 없으면 기록하지 않습니다).

## 되돌리기

**변경** 탭에서 항목 옆 ↺로 하나씩, 아래 **모두 되돌리기**로 전부 되돌립니다. 마지막으로 **제출된** 상태로 돌아갑니다(기록만 한 변경도 되돌립니다). 다 되돌리면 기록도 정리됩니다.
