## 설치와 첫 실행

[설치 가이드](../../app/INSTALL.md)를 따라 dmg를 설치합니다. 첫 실행 때는 앱이 순서대로 안내합니다.

| 단계 | 하는 일 |
|---|---|
| 1. GitHub 연결 | GitHub 토큰을 붙여 넣습니다. 앱 안의 링크로 토큰 만드는 페이지가 열립니다 |
| 2. 매뉴얼 내려받기 | 기본 위치는 `~/Documents/Ariadne`입니다 |
| 3. 환경 점검 | 목록이 모두 초록색(또는 `선택` 항목만 노란색)이면 **시작하기** |

환경 점검에서 앱이 알아서 받아 설치하는 것과 직접 설치하는 것:

| 도구 | 쓰는 곳 | 설치 |
|---|---|---|
| pandoc (약 40MB) | 미리보기, Word 만들기 | 앱이 자동으로 |
| Claude Code (약 220MB) | Claude로 초안, 최신화, 영상 | 앱이 자동으로 (앱 전용 버전) |
| Google Chrome | 화면 캡처, 영상, Claude의 STG 확인 | 직접 |

두 번째 실행부터는 바로 편집 화면이 열립니다. 열 때마다 다른 사람이 올린 변경을 자동으로 받아 오고, 앱 전용 Claude Code가 없으면(예전 버전에서 업데이트했거나 앱이 Claude Code 버전을 올렸을 때) 뒤에서 받습니다.

### 위쪽

| 영역 | 설명 |
|---|---|
| 매뉴얼 이름 | 누르면 다른 매뉴얼로 바꾸거나 [새 매뉴얼을 가져옵니다](import.md) |
| 동기화 표시 | `최신`, `새 변경 있음`, `합칠 변경 있음`, `오프라인`. 누르면 다시 받아 옵니다 |
| 작업 표시 | 도는 작업(예: `Claude 최신화 · 3:12`, `영상 만들기 · 장면 2/5`, `대기 2`). 누르면 그 패널이 다시 열립니다 |
| 캡처, 영상, Word 만들기, 제출, ⚙ | [화면 캡처](capture.md), [가이드 영상](video.md), [Word 만들기와 제출](editing.md#word-만들기), [설정](settings.md) |

### 왼쪽

| 탭 | 설명 |
|---|---|
| 목차 | 장과 화면 목록. 노란 숫자는 남은 TODO 수, 빨간 점은 아직 제출하지 않은 변경, `검토`는 Claude가 고쳐 아직 검토하지 않은 화면 |
| TODO | 매뉴얼 전체의 TODO 모음. 누르면 그 줄로 이동합니다 |
| 변경 | 제출 전 변경 목록. 항목마다 되돌릴 수 있습니다 |

### 가운데와 오른쪽

| 영역 | 설명 |
|---|---|
| 편집 / ◫ / 미리보기 | 편집기만, 나란히, 미리보기만 보기 |
| 섹션 정보 | 코드와 매뉴얼을 잇는 값(routes, sources, i18nPrefix). 기획자는 건드리지 않아도 됩니다 |
