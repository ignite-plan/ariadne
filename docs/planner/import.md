# 새 매뉴얼 가져오기

[← 기획자 사용법](README.md)

BO 매뉴얼과 같은 형식의 Word 원본(FO 매뉴얼 등)으로 새 매뉴얼을 만듭니다.

1. 위쪽 매뉴얼 이름 → **새 매뉴얼 가져오기…**
2. **Word 파일 고르기…**로 원본을 고릅니다. 앱이 장, 화면, 이미지 수를 분석해 보여 줍니다. 이 단계에서는 아무것도 바뀌지 않습니다.
   - 노란 경고가 있으면 내용을 확인합니다. 예: 목차의 제목을 본문에서 못 찾은 경우, 이미지 수가 맞지 않는 경우
3. 정보를 확인합니다. 대부분 자동으로 채워집니다.

   | 항목 | 설명 |
   |---|---|
   | 매뉴얼 제목 | 표지에서 가져옵니다. 예: `Dealers FO User Manual` |
   | id | 폴더 이름(영문). 제목에서 만듭니다. 예: `fo` |
   | 버전 | 파일 이름의 `_v1.2.3`에서 가져옵니다. 없으면 `1.0.0` |
   | Word 파일 이름 | Word 만들기로 생기는 파일 이름. `{version}`은 버전으로 바뀝니다 |
   | 화면(코드) 연결 | 딜러포털 FO / BO / Dealer Profile. 고르면 캡처 주소가 채워집니다 |
   | 캡처 주소, 화면 크기 | STG 주소와 PC/모바일 |
   | 원본 Word 보관 | 켜 두면 `manuals/<id>/source/`에 원본을 같이 둡니다(나중에 서식을 다시 뽑을 때 필요) |

4. **가져오기**를 누르면 새 매뉴얼로 바뀝니다. 미리보기로 확인하고 **제출**합니다.

- 이미지 캡션은 Word 그림의 대체 텍스트와, 그림 바로 아래 **캡션 스타일** 문단에서 가져옵니다. 캡션 문단은 이미지 캡션 `![캡션](images/…)`으로 옮기고 본문에서는 뺍니다(Word 만들기에서 다시 캡션 서식으로 나옵니다). 그림 두 장이 한 줄에 있어 캡션 하나를 같이 쓰는 경우처럼 어느 그림의 캡션인지 정할 수 없으면 본문 문단으로 남습니다.

> [!NOTE]
> 가져온 매뉴얼은 자동 캡처 정의가 비어 있습니다. 캡처가 필요하면 개발자에게 `shots.ts` 추가를 요청하거나, [Claude로 최신화](claude-features.md#claude로-최신화)를 돌려 채웁니다.

> [!TIP]
> 잘못 가져왔으면 제출 전에 다른 매뉴얼로 바꾼 뒤 **변경** 탭의 **모두 되돌리기**로 지웁니다.

## 매뉴얼 삭제

잘못 가져왔거나 더 쓰지 않는 매뉴얼을 지웁니다.

1. 위쪽 매뉴얼 이름을 누르고, 지울 매뉴얼 줄에 마우스를 올려 휴지통을 누릅니다.
2. 화면·이미지 수를 확인하고, 확인칸에 매뉴얼 id를 그대로 입력한 뒤 **삭제**를 누릅니다.
3. **변경** 탭에 `매뉴얼 삭제: <id> (파일 N개)` 한 줄이 생깁니다. **제출**하면 모든 사람의 앱에서 사라집니다.

- 지금 열린 매뉴얼은 지울 수 없습니다. 다른 매뉴얼로 바꾼 뒤 지웁니다. 매뉴얼이 하나뿐이어도 지울 수 없습니다.
- 제출하기 전에는 변경 탭에서 그 줄을 ↺로 되돌리면 매뉴얼이 그대로 돌아옵니다.
- 본문, 이미지, 원본 Word, 자동 캡처 정의, 가이드 영상 시나리오가 함께 지워집니다.
