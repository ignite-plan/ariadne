# 가이드 영상 만들기

[← 기획자 사용법](README.md)

STG 화면을 녹화하고 영어 자막과 영어 내레이션을 넣어 사용법 영상(mp4)을 만듭니다. 영상은 시나리오(장면 목록)로 만들어서, 화면이 바뀌면 같은 시나리오로 다시 만들면 됩니다.

## 만드는 순서

1. 위쪽 **영상**을 누릅니다. 처음이면 왼쪽에서 **로그인**(캡처와 같은 세션)과 음성 모델 **받기**(약 90MB, 한 번만)를 합니다.
2. **새 영상**을 누르고 연결할 화면과 영상 제목(영어)을 정합니다. 두 화면 이상을 한 영상으로 이어서 보여 주려면 **(화면 추가)**로 화면을 더 고릅니다. 고른 순서대로 영상에 나옵니다. 장면 탭 맨 위에서 나중에 바꿀 수도 있습니다.
3. 장면을 채웁니다. 아래 [장면 채우는 네 가지 방법](#장면-채우는-네-가지-방법)을 섞어 써도 됩니다.
4. 내레이션 옆 스피커 버튼으로 **음성을 들어 봅니다**. 화면 자막을 더 짧게 하려면 **화면 자막을 따로 쓰기**를 누릅니다.
5. **미리보기**(처음부터) 또는 장면의 **여기부터 미리보기**로 Chrome 창에서 실행해 봅니다. 녹화하지 않습니다. 실패하면 그 단계가 빨갛게 표시됩니다.
6. **영상 만들기**를 누릅니다. **영상** 탭에서 바로 재생하고, **Finder에서 보기**로 파일(`dist/videos/<id>.mp4`, 자막 `.srt`, `.vtt`)을 엽니다.
7. 시나리오는 자동 저장되고 **제출**에 포함됩니다.

> [!NOTE]
> 영상 파일은 크기 때문에 제출하지 않습니다. 필요한 곳에 따로 올립니다.

## YAML로 가져오기·내보내기

시나리오는 `manuals/<매뉴얼>/videos/<id>.yaml` 파일입니다. 같은 형식의 파일을 직접 쓰거나 다른 매뉴얼·PC에서 옮길 때 씁니다.

- **YAML 가져오기**: 파일을 고르면 형식을 검사한 뒤 장면·단계가 채워진 영상으로 넣습니다. 파일 이름이 영상 id가 됩니다(영문 소문자, 숫자, `-`로 바뀜). 형식이 틀리면 어느 줄이 틀렸는지 알려 주고 넣지 않습니다.
  - 같은 id의 영상이 이미 있으면 **바꾸기**(그 영상 내용을 파일 내용으로) 또는 **새 영상으로 추가**를 고릅니다. 바꾼 것은 제출 전까지 변경 탭에서 되돌릴 수 있습니다.
- **YAML 내보내기**: 고른 영상의 시나리오를 파일로 저장합니다(기본 위치는 다운로드 폴더).

## 장면 채우는 네 가지 방법

| 방법 | 범위 | 하는 일 |
|---|---|---|
| **Claude로 초안** | 영상 전체 | 연결한 매뉴얼 화면(여러 개면 고른 순서대로 이어서)의 문장으로 내레이션을 쓰고, STG 화면을 확인해 단계를 만든 뒤 끝까지 실행해 봅니다. 몇 분 걸리고 내 Claude 사용량을 씁니다 |
| **Claude로 이 장면** | 장면 하나 | 보여 줄 내용을 한국어로 적으면 Claude가 앞 장면을 재생해 그 화면을 열고, 이 장면의 내레이션과 단계를 채운 뒤 실행해 봅니다. 다른 장면은 바꾸지 않습니다 |
| **STG에서 기록** | 장면 하나 | Chrome 창이 열리면 평소처럼 누르고 입력합니다. 누른 것이 그 장면의 단계로 붙습니다 |
| **직접 쓰기** | 장면 하나 | 내레이션을 쓰고 **+ 단계**로 화면 열기, 클릭, 입력, 선택, 강조, 멈춤을 넣습니다 |

**Claude로 초안**

- 패널의 **Claude에게 요청 (선택)** 칸에 보여 줄 범위나 순서를 한국어로 적을 수 있습니다. 예: "검색 조건은 Dealer Name만 보여 주기, 장면은 5개 이내"
- 저장·삭제 버튼 금지와 STG 저장 허용을 Claude가 켜지 않는 규칙은 요청으로 바뀌지 않습니다.

**Claude로 이 장면**

- 예: "Job title 탭에서 Edit을 눌러 팝업에서 체크박스를 고르는 화면"
- **장면 n 채우기**(지금 내용을 바꿈) 또는 **장면 n 다음에 새 장면으로 추가**를 고릅니다.
- STG에 실제 저장 허용 영상에서는 쓸 수 없습니다.

**STG에서 기록**: Chrome 창 오른쪽 아래 막대

| 버튼 | 하는 일 |
|---|---|
| 강조할 곳 고르기 | 누르지 않고 강조 |
| 가릴 곳 고르기 | 영상에서 흐리게 |
| 기다릴 글자 고르기 | 그 글자가 보일 때까지 기다림 |
| 새 장면 | 다음 장면으로 이어서 기록 |
| 기록 끝 | 기록 마침 |

기록한 단계가 이름 없는 아이콘을 눌렀다면 기록 막대에 경고가 나옵니다. 미리보기로 맞는지 확인하세요.

## 영상마다 고르는 설정

기본 정보에서 고릅니다.

| 설정 | 선택지 |
|---|---|
| 자막 크기 | 작게, 보통, 크게 |
| 내레이션 속도 | 0.8× ~ 1.3× (자막이 떠 있는 시간도 같이 바뀜) |
| 조작 속도 | 느리게, 보통, 빠르게 (커서, 입력, 강조, 장면 사이 쉬는 시간) |
| 이메일·전화번호 가리기 | 화면에서 이메일, 전화번호처럼 보이는 글자를 자동으로 흐리게 |
| STG에 실제 저장 허용 | 생성, 수정 과정을 끝까지 보여 줘야 할 때만 (아래) |

## STG 저장과 안전

기본적으로 저장, 삭제, 발송, 승인 버튼은 누르지 않고, 데이터를 바꾸는 요청도 막습니다. 막은 요청은 목록으로 알려 줍니다.

> [!WARNING]
> **STG에 실제 저장 허용**을 켜면 STG 데이터가 실제로 바뀝니다.
> - 입력값은 `Video Test {stamp}`처럼 테스트 데이터임을 알 수 있게 씁니다(`{stamp}`는 실행 시각).
> - **정리 단계**에 만든 데이터를 지우는 단계를 넣습니다.
> - Claude는 이 설정을 켜지 않습니다.
