# 기획자 사용법

[← README](../../README.md)

macOS 앱 **Ariadne**로 매뉴얼을 고치고, 화면을 캡처하고, Word를 만들고, 제출합니다. 터미널과 git은 몰라도 됩니다.

## 처음이라면

1. [설치 가이드](../../app/INSTALL.md)대로 dmg를 설치합니다.
2. [설치와 화면 구성](getting-started.md)에서 첫 실행 순서와 화면을 익힙니다.
3. [편집과 제출](editing.md)로 문장을 고치고 제출해 봅니다.
