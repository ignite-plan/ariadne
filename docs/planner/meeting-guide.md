[← 기획자 사용법](README.md)

## 0. 미팅 전 준비 (진행자)

- [ ] **1.10.0 이상이 배포됐는지** 확인: https://github.com/ignite-plan/ariadne/releases/latest 에 `Ariadne-1.10.0-arm64.dmg`(또는 더 새 버전)가 있는지. 이미 설치한 참석자는 앱 위쪽 알림의 **업데이트**로 올려 오게 공지
- [ ] 참석자 **GitHub 계정을 `ignite-plan/ariadne`에 쓰기 권한으로 초대**하고, 초대 수락까지 받아 두기 (수락 안 하면 설치 파일이 안 보임)
- [ ] 참석자에게 미리 공지: Apple Silicon Mac, **Google Chrome 설치**, **STG 계정(MFA) 준비**, 회의 중 휴대폰(MFA용) 지참
- [ ] Claude 기능을 각자 해 볼 사람은 `~/.zshrc`에 `ANTHROPIC_API_KEY`가 있고, 터미널에서 `claude mcp list`에 Atlassian이 연결돼 있는지 미리 확인 (Claude Code 자체는 앱이 앱 전용 버전을 받아 씀)
- [ ] **실습 화면 배정표** 만들기 (8번 Claude 실습에서 같은 화면을 두 사람이 동시에 돌리지 않게). 부록의 표 사용
- [ ] 진행자 Mac에 앱 설치·로그인을 끝내 두고, 화면 공유 준비

## 1. 오프닝과 실습 규칙 (5분)

**말할 것**

> 오늘은 사용자 매뉴얼을 고치는 앱 Ariadne를 다같이 설치하고, 실제로 문장 고치기, 화면 캡처, Word 만들기, Claude 기능까지 직접 해 보겠습니다.
>
> Ariadne에서는 매뉴얼 원본이 Word가 아니라 화면 하나당 파일 하나인 텍스트입니다. Word는 버튼 하나로 만드는 결과물입니다. 여러 사람이 동시에 고쳐도 앱이 합쳐 주고, 터미널이나 git은 몰라도 됩니다.

> [!IMPORTANT]
> 실습 규칙은 꼭 강조합니다. 연습한 내용은 제출하지 않고, 실습마다 되돌립니다.

**말할 것 — 실습 규칙**

> 오늘 연습하면서 고친 내용은 **절대 제출하지 않습니다.** 지금 보는 매뉴얼은 실제 매뉴얼이라, 제출하면 다른 분들 앱에도 바로 반영됩니다.
>
> 실습이 끝날 때마다 **변경 탭에서 모두 되돌리기**를 같이 하겠습니다. 제출 버튼은 오늘 마지막에 설명만 합니다.

## 2. 설치 (10분)

**말할 것**

> 설치 파일은 GitHub에 있습니다. 메일로 받은 GitHub 초대를 수락하셨으면 링크가 열립니다.

**다같이**

1. 브라우저에서 https://github.com/ignite-plan/ariadne/releases/latest 를 엽니다. (채팅방에 링크 공유)
2. 아래 **Assets**에서 `Ariadne-1.10.0-arm64.dmg`(가장 새 버전)를 받습니다.
3. dmg를 열고 **Ariadne** 아이콘을 **응용 프로그램** 폴더로 끌어 놓습니다.
4. 응용 프로그램에서 Ariadne를 엽니다. "확인되지 않은 개발자" 경고가 뜨면:
   - **시스템 설정 → 개인정보 보호 및 보안** → 아래쪽 "Ariadne이(가) 차단되었습니다" 옆 **그래도 열기** → 한 번 더 **열기**

**말할 것**

> 경고는 사내 배포용이라 Apple 공증을 받지 않아서 뜨는 것이고, 처음 한 번만 하면 됩니다.

**확인**: 모두 "GitHub 연결" 화면이 떠 있는지.

**막히면**

| 증상 | 해결 |
|---|---|
| 링크가 404 | GitHub 초대를 아직 수락하지 않음 → 메일의 초대 수락 후 새로고침 |
| "그래도 열기"가 안 보임 | 앱을 한 번 열어 경고를 띄운 뒤 시스템 설정을 다시 열기 |
| 그래도 안 열림 | 터미널에서 `xattr -dr com.apple.quarantine /Applications/Ariadne.app` 후 다시 열기 (진행자가 대신) |

## 3. 첫 실행 (15분)

### 3-1. GitHub 연결

**말할 것**

> 앱이 매뉴얼을 내려받고 제출하려면 GitHub 토큰이 필요합니다. 앱 안의 버튼으로 토큰 만드는 페이지를 열겠습니다. 화면 공유를 보면서 같이 채워 주세요.

**다같이**

1. 앱의 **토큰 만들기 페이지 열기**를 누릅니다.
2. GitHub 페이지에서:
   - Token name: `Ariadne` · Expiration: 원하는 기간
   - Resource owner: **`ignite-plan`**
   - Repository access: **Only select repositories** → **`ariadne`**
   - Permissions → Repository permissions:
     - **Contents**: Read and write
     - **Pull requests**: Read and write
     - **Issues**: Read and write
3. **Generate token** → 만들어진 `github_pat_…`를 복사해 앱에 붙여 넣고 **연결**.

**막히면**

| 증상 | 해결 |
|---|---|
| Resource owner에 `ignite-plan`이 없음 | 초대 미수락 → 수락 후 페이지 새로고침 |
| "권한이 없습니다" / SSO | 토큰 목록에서 `ignite-plan` 조직 SSO 승인(Configure SSO → Authorize) |
| fine-grained 토큰이 조직 승인 대기 | 진행자가 조직 관리자에게 승인 요청. 급하면 classic 토큰(`repo` 권한)으로 진행 |

### 3-2. 매뉴얼 내려받기

**다같이**: 폴더는 그대로(`~/Documents/Ariadne`) 두고 **내려받기**. 약 40MB, 1분 안쪽.

### 3-3. 환경 점검

**말할 것**

> 미리보기와 Word 만들기에 쓰는 pandoc, 그리고 Claude 기능에 쓰는 앱 전용 Claude Code를 앱이 알아서 받아 설치합니다. 모두 같은 버전으로 돌게 하려는 것입니다. Claude Code가 약 220MB라 1~2분 걸릴 수 있습니다.

**다같이**: 목록이 모두 초록색(또는 "선택" 항목만 노란색)이 되면 **시작하기**.

**확인**: 모두 편집 화면(왼쪽 목차, 가운데 편집기)이 떠 있는지.

## 4. 화면 둘러보기 (5분)

**말할 것** (진행자 화면을 가리키며)

> 위쪽 왼쪽은 지금 매뉴얼 이름과 **동기화 표시**입니다. `최신`이면 다른 분들이 올린 변경까지 다 받아 온 상태입니다. 앱을 열 때마다 자동으로 받아 옵니다.
>
> 위쪽 오른쪽 버튼은 **캡처, 영상, Word 만들기, 제출, 설정**입니다. Claude 작업이나 영상 만들기가 돌면 그 왼쪽에 작업 표시(예: `Claude 최신화 · 2:10`)가 생기고, 누르면 진행 패널이 다시 열립니다.
>
> 왼쪽 탭은 세 개입니다. **목차**는 장과 화면, **TODO**는 확인이 필요한 메모 모음, **변경**은 아직 제출하지 않은 내 수정입니다. 목차의 `검토` 표시는 Claude가 고쳤는데 아직 검토하지 않은 화면입니다.
>
> 가운데가 편집기, 오른쪽이 Word와 같은 모양의 미리보기입니다. 위쪽 "편집 / ◫ / 미리보기"로 나란히 보거나 하나만 볼 수 있습니다.
>
> 화면 위쪽 "섹션 정보"는 개발용 값이라 건드리지 않으셔도 됩니다.

## 5. 실습 1: 문장 고치기 → 변경 보기 → 되돌리기 (10분)

**다같이**

1. 왼쪽 목차에서 **2. Dealer Management → Dealer List View**를 엽니다. (또는 **화면 찾기**에 `Dealer List`)
2. 편집기에서 아무 문장 끝에 단어 하나를 추가해 봅니다.
3. 오른쪽 미리보기가 바로 바뀌는지 봅니다. 입력을 멈추면 위쪽에 **저장됨**이 뜹니다.
4. 툴바를 눌러 봅니다:
   - **B** → `**Label**` (항목 이름)
   - **[ ]** → `[Button]` (버튼 이름)
   - **⚑** → TODO 메모 (Word에는 안 나옴). 왼쪽 **TODO** 탭에 생기는지 확인
5. 왼쪽 **변경** 탭 → Dealer List View 옆 **⑂**(변경 보기) → 빨간 줄은 지운 것, 초록 줄은 추가한 것
6. **모두 되돌리기**(변경이 하나면 항목 옆 **↺**) → **되돌리기**

**확인**: 모두 변경 탭에 "제출할 변경이 없습니다"가 보이는지.

**말할 것**

> 이렇게 고치고, 미리보기로 보고, 변경 보기로 확인한 뒤 제출하는 게 기본 흐름입니다. 제출은 마지막에 설명드리겠습니다.

## 6. 실습 2: STG 로그인 → 화면 캡처 (10분)

**말할 것**

> 화면이 바뀌면 매뉴얼 이미지를 STG에서 다시 찍을 수 있습니다. 먼저 STG에 한 번 로그인하겠습니다. 이 로그인은 캡처, 가이드 영상, Claude 기능이 같이 씁니다.

**다같이**

1. 위쪽 **캡처** → **로그인**
2. 열린 Chrome 창에서 STG 로그인 (MFA 포함) → STG 화면이 보이면 앱에서 **로그인 완료**
3. 실습 1의 Dealer List View를 연 상태에서 **지금 화면** → 이미지 1장만 체크 → **1장 캡처**
4. "지금 매뉴얼 / 새로 찍은 화면"이 나란히 나오면 비교만 해 봅니다. (화면이 그대로면 "바뀐 이미지가 없습니다"가 정상)
5. **반영하지 않고** 닫습니다. 반영했다면 변경 탭에서 되돌리기.

**말할 것**

> 캡처는 화면을 열고 찍기만 합니다. 저장이나 삭제 버튼은 누르지 않습니다.
>
> "이 화면에는 자동 캡처가 정의되어 있지 않습니다"가 나오는 화면은 아직 자동으로 찍는 방법이 등록되지 않은 화면입니다. 그 화면은 직접 캡처해서 편집기에 붙여 넣거나(⌘V), 뒤에서 볼 Claude 최신화를 한 번 돌리면 등록됩니다.

**막히면**

| 증상 | 해결 |
|---|---|
| 로그인 Chrome 창이 안 뜸 | 설정 → 환경 점검에서 Chrome 확인 |
| "세션 만료" | 캡처 화면에서 **다시 로그인** |
| 로그인 버튼이 꺼져 있음 | 다른 STG 작업(Claude, 영상 만들기, 캡처)이 도는 중. 마우스를 올리면 이유가 보임 |

## 8. Claude 기능 (20분)

**말할 것**

> Claude는 Confluence 기획서와 실제 STG 화면을 보고 매뉴얼을 쓰거나 고칩니다. 두 가지가 있습니다.
>
> - **Claude로 초안 만들기**: 매뉴얼에 없는 새 메뉴의 화면들을 처음부터 씁니다.
> - **Claude로 최신화**: 이미 있는 화면을 최신 기획서에 맞춰 바뀐 곳만 고칩니다.
>
> 기획서와 화면이 다르면 Claude가 판단하지 않고 TODO로 남깁니다. 그래서 끝나면 꼭 **Claude 변경 표시**와 TODO 탭을 확인해야 합니다.
>
> 저장·삭제·승인·발송 버튼은 앱이 막고, STG 데이터를 바꾸는 요청도 막습니다.

### 8-1. 진행자 시연: 최신화 (화면 공유)

1. 목차에서 화면 하나에 마우스를 올려 **✦** → 점검 화면 설명
   - Claude Code, Confluence 연결, STG 로그인이 초록색인지
2. **최신화 시작** → 로그가 한 줄씩 나오는 것, 화면별 진행 칩 설명
3. **숨기기** → 위쪽 작업 표시(예: `Claude 최신화 · 2:10`) → 눌러서 다시 열기
   - "작업이 도는 동안에도 다른 화면을 고치고, 캡처나 영상 만들기도 같이 할 수 있습니다. 끝나면 알림이 뜹니다. 대신 Claude가 고치는 화면은 끝날 때까지 편집이 막히고, 그동안은 제출할 수 없습니다."
4. **대기열**: 도는 중에 목차에서 다른 화면의 **✦** → **대기에 추가 (1번째)**
   - 위쪽 작업 표시에 `대기 1`이 붙는 것, 진행 패널의 **대기 중인 최신화**에서 ↑ ↓로 순서를 바꾸고 뺄 수 있는 것을 보여 줌
   - "앞 작업이 끝나면 다음 작업이 저절로 시작합니다. 시작 전에 STG 로그인을 확인해서, 만료됐으면 대기열이 멈춤이 됩니다. 다시 로그인하고 **계속**을 누르면 됩니다. 대기열은 앱을 켜 둔 동안만 있고, 작업이나 대기가 남은 채로 앱을 끄면 확인 창이 뜹니다."
   - 시연 뒤 대기 항목은 빼 둠 (시간 절약)
5. 끝나면 결과 요약 → 고친 화면을 누르면 그 화면이 열림
6. **Claude 변경 검토** (꼭 보여 줄 것)
   - 목차에 `검토` 표시, 화면 위쪽 **Claude 변경** 막대
   - 미리보기: Claude가 넣은 글자는 초록 밑줄, 지운 글자는 빨간 취소선. 편집기: 바뀐 줄 왼쪽 막대
   - 막대의 ↑ ↓로 변경 사이 이동 → **검토 완료** (표시만 꺼지고 내용은 그대로)
7. 시연한 변경은 변경 탭에서 되돌리기

**말할 것 — 검토 표시**

> Claude 변경 표시는 Claude가 고치기 직전 본문과 비교합니다. 그래서 제가 전에 고친 내용과 섞이지 않고, 검토 전에 같은 화면을 다시 최신화해도 처음 원문과 비교합니다. 이 표시는 앱 화면에만 보이고 Word에는 들어가지 않습니다. 노란 형광펜과는 다른 기능입니다. 제출하거나 되돌리면 표시가 사라집니다.

**말할 것 — 반영 범위**

> 특정 기간이나 Jira 티켓의 변경만 반영하고 싶을 때는 시작 전에 **반영 범위**에 기간이나 티켓을 넣습니다. 예를 들어 5월부터 8월까지만 반영하면 9월 이후 변경은 반영하지 않고, 해당 변경이 없는 화면은 건너뜁니다. 이때는 STG에 이후 변경이 들어가 있을 수 있어서 캡처는 다시 찍지 않습니다.

(진행자: 반영 범위 입력칸만 보여 주고 시작하지 않음)

### 8-2. 다같이: 각자 화면 하나 최신화 (선택)

> 터미널에서 Claude Code와 Atlassian MCP를 이미 쓰고 있는 분만 따라 합니다. 각자 Claude 사용량이 듭니다.

**다같이**

1. **배정표의 내 화면**을 목차에서 찾아 마우스를 올리고 **✦**
2. 점검 화면이 모두 초록색인지 확인 (Confluence가 노란색이면 **다시 확인**)
3. **최신화 시작** → 기다리는 동안 **숨기기**로 접어 두고 다음 설명을 듣습니다.
4. 끝나면 목차의 `검토` 화면을 열어 초록·빨강 표시를 보고 **검토 완료** → **변경 탭에서 모두 되돌리기**

**말할 것**

> 화면 하나에 보통 몇 분에서 10분쯤 걸립니다. 같은 화면을 두 사람이 동시에 돌리면 결과가 겹치니 배정표대로 해 주세요. 평소에는 여러 화면을 대기에 걸어 두고 다른 일을 하시면 됩니다.

### 8-3. 초안 만들기 (설명만)

> 새 메뉴는 목차 아래 **새 화면 → Claude로 초안 만들기**에서 메뉴 이름(영어)과 넣을 장을 고르고 시작합니다. 장 전체의 문체를 맞추려고 Claude 하나가 화면을 순서대로 써서 메뉴 크기에 따라 수십 분 걸립니다.

## 9. 가이드 영상 시연 (5분)

**진행자 시연**

1. 위쪽 **영상** → 기존 영상 하나 재생
2. 영상 하나를 열어 장면 목록 보여 주기: 장면마다 영어 내레이션 + 단계(화면 열기, 클릭, 입력, 강조)
3. 장면 채우는 방법 네 가지 설명:
   - **Claude로 초안**(전체) · **Claude로 이 장면**(한국어로 요청) · **STG에서 기록**(직접 눌러서) · **직접 쓰기**
4. **Claude로 이 장면**의 두 선택지:
   - "장면 n 채우기": 그 장면 내용을 바꿉니다.
   - "장면 n 다음에 새 장면으로 추가": 그 장면은 두고 뒤에 하나를 끼워 넣습니다.

**말할 것**

> 처음 영상을 만들 때 음성 모델(약 90MB)을 한 번 받습니다. 시나리오는 제출에 포함되고, 영상 파일은 크기 때문에 따로 올립니다.

## 10. 마무리 (5분)

### 제출 (설명만)

**말할 것**

> 실제로 고친 내용은 위쪽 **제출** → 바뀐 화면 확인 → 한 줄 설명 → **제출하고 바로 반영**으로 올립니다. 다른 분의 변경은 앱이 자동으로 합칩니다.
>
> 같은 문장을 두 사람이 동시에 고쳐 합칠 수 없으면, 앱이 개발자에게 넘기고 안내가 뜹니다. 그때는 **같은 수정을 다시 하지 말고** 기다려 주세요. 수정은 사라지지 않습니다. 충돌을 줄이려면 같은 화면은 한 사람이 맡고, 고친 뒤 바로 제출해 주세요.

### 작성 규칙

**말할 것**

> - 영어, 현재형, 짧은 문장으로 씁니다.
> - 항목은 `**Label**: 설명`, 버튼은 `[Label]`.
> - **UI 라벨은 실제 화면 문구 그대로** 씁니다. 기획서와 화면이 다르면 고치지 말고 TODO로 남깁니다.
> - 근거 없는 내용은 추측해서 쓰지 않고 TODO로 남깁니다.

### 문제 신고와 업데이트

**말할 것**

> 문제가 생기면 **설정 → 정보 → 문제 신고**로 알려 주세요. 오류 기록이 같이 첨부됩니다.
>
> 새 버전이 나오면 앱 위쪽에 알림이 뜹니다. **업데이트**를 누르면 새 버전을 받아 두고, **지금 다시 시작**을 누르면 바뀐 뒤 다시 열립니다. 1분 안쪽입니다. Claude 작업이나 영상 만들기 중에는 끝난 뒤 누르시면 됩니다. 잘 안 되면 알림의 **직접 받기**로 dmg를 받아 덮어 설치합니다.
>
> 기능별 자세한 사용법은 저장소의 `docs/planner/` 문서(기획자 사용법)에 있습니다.

**마지막 확인 (다같이)**: 왼쪽 **변경** 탭에 "제출할 변경이 없습니다"가 보이는지. 남아 있으면 **모두 되돌리기**.
