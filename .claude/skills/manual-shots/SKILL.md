# 캡처 정의 만들기 (STG)

사람에게 묻지 않고 끝까지 진행한다. **본문과 매뉴얼 이미지는 바꾸지 않는다.** 할 일은 "이 이미지를 STG에서 다시 찍는 방법"을 `save_shot`으로 등록하는 것뿐이다. 기획자는 나중에 앱의 캡처 버튼으로 다시 찍어 비교하고 반영한다.

앱은 화면마다 이 작업을 따로(여러 개 동시에) 실행한다. **대상 화면 하나의 이미지만 다룬다.**

## 입력 (프롬프트 끝 "이번 작업")
- 매뉴얼 id, 메뉴(장) 이름, 대상 화면 파일, STG 경로 힌트
- **정의할 이미지**: 이 화면이 쓰는 이미지 중 자동 캡처가 없는 id. `save_shot`은 이 id만 받는다

## 도구
- `mcp__ariadne__*`: `stg_open`/`stg_click`/`stg_fill`, `save_shot`(이 작업에서는 정의만 등록하고 찍은 결과 파일 경로를 돌려준다), `drop_shot`(이번에 등록한 정의 빼기)
- Read/Glob/Grep. Edit/Write, Confluence, Bash, 웹은 없다

## 1. 이미지마다 무엇을 찍었는지 알아내기
1. 대상 화면 파일을 Read로 읽는다. 정의할 이미지마다 캡션(`![Caption](images/<id>.png)`), 앞뒤 문장(어떤 팝업·탭·입력 상태를 설명하는지), front-matter `routes`를 정리한다
2. 이미지 파일(`manuals/<id>/images/<id>.png`)을 Read로 본다. 전체 화면인지, 팝업만인지, 화면 일부(검색 영역 등)인지, 어떤 탭·입력 상태인지 확인한다
3. 이미 정의가 있는 이미지의 형식은 `manuals/<id>/shots.ts`를 참고한다 (path, ready, steps, clip)

## 2. STG에서 같은 화면 상태 만들기
1. `routes`(없으면 STG 경로 힌트)로 `stg_open`. 접근성 트리로 화면을 확인한다
2. 팝업·탭·상세 화면은 `stg_click`, 입력 상태는 `stg_fill`로 이미지와 같은 상태를 만든다
3. **저장/삭제/승인/발송/등록 버튼은 누르지 않는다** (앱이 거절하고 쓰기 요청도 막는다). 저장해야만 보이는 화면(완료 메시지, 저장 후 상세)은 정의하지 않는다
4. 세션 만료로 로그인 페이지가 나오면 멈추고 마지막 응답에 적는다

## 3. 등록하고 확인하기
1. 이미지마다 `save_shot`을 부른다
   - `path`: 화면 경로, `ready`: 화면 준비 완료 표식(접근성 트리에서 본 텍스트, 예: `text=Total`)
   - `steps`: 실제로 해 본 순서 그대로 (`click`/`fill`/`waitFor`)
   - `clip`: 팝업은 `[role="dialog"]`, 전체 화면은 `#root`, 화면 일부는 그 영역 locator
2. 응답의 `captured`(찍은 결과)와 `manual`(매뉴얼 이미지)을 **둘 다 Read로 보고** 같은 화면·같은 상태·같은 영역인지 비교한다
   - 데이터(목록 행, 날짜, 개수)나 사소한 문구가 다른 것은 괜찮다. 화면 구성이 바뀐 것도 괜찮다(기획자가 비교해 반영한다)
   - 다른 화면, 다른 팝업, 다른 탭, 잘린 영역이 다르면 steps·clip을 고쳐 같은 id로 다시 `save_shot` (한 이미지에 3번까지)
   - 그래도 같은 상태를 만들 수 없으면 `drop_shot`으로 빼고 이유를 남긴다
3. 이렇게 다시 만들 수 없는 이미지는 등록하지 않는다
   - 화면에서 잘라 낸 아이콘·작은 조각, 여러 화면을 합친 그림
   - 저장·발송 뒤에만 보이는 상태, 특정 데이터가 있어야만 보이는 상태(찾지 못하면)

## 4. 마지막 응답
짧은 한국어 요약(이미지별로 등록했는지, 못 했으면 이유 한 줄) 뒤에 JSON 블록 하나로 끝낸다. `images`는 **등록하고 남겨 둔** 이미지 id만:

```json
{
  "sections": [],
  "images": ["menu-list", "menu-create-popup"],
  "todos": 0,
  "notes": "menu-icon-edit: 잘라 낸 아이콘이라 등록하지 않음"
}
```
